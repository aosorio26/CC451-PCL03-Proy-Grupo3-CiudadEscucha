# Evidencia visual de ejecución

Capturas tomadas por Playwright en Microsoft Edge sobre el build de producción local. No son maquetas ni imágenes generadas.

- 01 Inicio de escritorio, 1440 px.
- 02 Mapa de calor calculado con incidencias del backend; el estado de cartografía externa se muestra en pantalla.
- 03 Incidencia creada por Lucía con apoyo y comentario de Julio en otra sesión.
- 04 Preferencias persistentes en modo oscuro.
- 05 Inicio móvil, 390 px.
- 06 Perfil de vecino y relación desde una cuenta recién registrada.
- 07 Texto al 180% y alto contraste en móvil.

Algunas capturas de página completa muestran barras fijas en la altura del viewport; no son contenido repetido en la página. Los registros de pruebas se identifican por su título. Para repetir: npm run test:e2e con el servidor demo iniciado y Edge instalado. No ejecutar contra datos de producción.
