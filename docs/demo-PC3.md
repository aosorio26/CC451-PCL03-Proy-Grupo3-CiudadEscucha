# Guion de sustentación PC3

La PC2 identifica cuatro integrantes. Se propone una distribución de **3 minutos por persona, 12 minutos máximo**, que el equipo debe aceptar antes de grabar. Esta propuesta no acredita contribuciones ya realizadas. Para tres o menos integrantes, ajustar al máximo de nueve minutos indicado por la rúbrica.

## Preparación

Iniciar el servidor, usar demo limpia y tres perfiles de navegador independientes: Lucía, Julio, Karina. Configurar y probar una clave LLM real antes de grabar. Probar el micrófono del equipo y mantener el texto alternativo disponible. Abrir las rutas antes de la exposición para evitar que el tiempo lo consuman instalaciones. No mostrar `.env` ni claves. Guardar la grabación fuera del repositorio si contiene datos personales.
