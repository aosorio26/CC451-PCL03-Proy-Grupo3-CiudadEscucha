# Cuentas para pruebas

Todas son ficticias. Contraseña común: **CiudadDemo2026!**. Requieren `DEMO_MODE=true` y `npm run seed`. El seed crea cuentas que falten; no restablece contraseñas ni borra registros. Los nuevos escenarios se cargan una sola vez, de modo que volver a ejecutarlo conserva los cambios y las amistades que hayas eliminado.

Ana, Mateo, Sofía, Diego, Valeria, Renato, Camila y Elena reciben dos reportes de ejemplo cada uno: uno reportado y otro resuelto, repartidos en varios distritos. Están identificados como demostración. No se agregan avatares de personas reales a estas cuentas: cada usuario puede subir una imagen propia desde Perfil.

Prueba sugerida: entra como Ana, sube un avatar, abre el perfil de Mateo y sus reportes; en otra sesión entra como Diego y acepta la solicitud. Como Luis, atiende una incidencia. Como Elena, consulta por voz «mis reportes resueltos». Cambiar de usuario requiere cerrar sesión o utilizar otro perfil del navegador.
